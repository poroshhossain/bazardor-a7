# 🛒 Bazardor-a7

A modern and responsive **Bazar / E-commerce website** built with a clean UI and dynamic product experience.

The project focuses on displaying products from an API, dynamic category-based navigation, product filtering, and sorting.

## ✨ Features

* 🏠 Modern and responsive homepage
* 🔝 Header section with:

  * Logo
  * Login
  * Sign Up
  * better auth feature sign in, sign up, logout, throwemail, google, github
  * Header actions
* 📂 Dynamic category-based navigation
* 📢 Marquee / promotional section
* 🌐 Dynamic product data fetched from API and product details page
* 🛍️ Responsive product card design
* 🔎 Product filtering
* ↕️ Product sorting
* 📱 Mobile-friendly responsive layout
* ⚡ Clean and reusable component structure

## 🧩 Main Sections

### Header

* Logo on the left
* Authentication actions on the right
* Responsive navigation

### Dynamic Navbar

Categories are dynamically loaded and displayed in the navigation menu.

### Marquee

A promotional marquee section is included to highlight important offers or messages.

### Product Section

Products are fetched from an API and displayed using reusable product cards.

### Filter & Sort

Users can filter products by category and sort products according to available sorting options.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/poroshhossain/Bazardor-a7.git
```

Go to the project directory:

```bash
cd Bazardor-a7
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
