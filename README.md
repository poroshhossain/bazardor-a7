# 🛒 বাজার দর | BazarDor

**BazarDor** is a modern, responsive online bazar website built with Next.js. It provides a dynamic product browsing experience with API integration, category-based navigation, product filtering, sorting, and user authentication.

## ✨ Key Features

1. **Responsive Homepage** — A clean, modern UI with a header, promotional marquee, and product sections.
2. **User Authentication** — Sign up, sign in, and sign out using Better Auth, with email and supported social login options.
3. **Dynamic Category Navigation** — Display product categories dynamically for easy browsing.
4. **API-Based Product Display** — Fetch products from an API and view individual product details.
5. **Product Filtering & Sorting** — Filter products by category and sort them using available options.

## 🛠️ Technologies Used

* **Framework:** Next.js, React
* **Language:** TypeScript / JavaScript
* **Styling & UI:** Tailwind CSS, HeroUI
* **Authentication:** Better Auth
* **Icons:** React Icons, Iconify
* **Notifications:** React Toastify
* **Data Integration:** API Integration

## 🚀 Getting Started

### Prerequisites

* Node.js
* npm

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/poroshhossain/Bazardor-a7.git
```

**2. Navigate to the project directory**

```bash
cd Bazardor-a7
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

> **Note:** Configure the required environment variables for authentication and other services if your project requires them.
